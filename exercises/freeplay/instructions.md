# Free Play

A blank canvas. Design and simulate any Verilog circuit you like.

Both `freeplay.v` and `tb_freeplay.v` contain only minimal boilerplate — edit them freely, rename ports and modules, or add new files as needed.

## Running a Simulation

Type the filenames you want to compile into the args box in the simulation panel, for example:

```
tb_freeplay.v freeplay.v
```

Then hit **Run**.
